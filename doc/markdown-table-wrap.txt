OVERVIEW                                      *markdown-table-wrap-overview*

markdown-table-wrap.nvim renders Markdown pipe tables with wrapped cell
content. It does not modify the source Markdown buffer. The default display
mode is source-position-preserving inline replacement; a floating preview is
available as an optional mode.

VIEW CHOICE                                  *markdown-table-wrap-view-choice*

Use Source for structural editing such as dd, Visual changes, moving rows, or
changing table delimiters. Use Inline when editing the original buffer while
keeping a rendered table layer visible.

|:MarkdownTableToggleInline| switches between Source and Inline. Press it
again to clear Inline and leave Source visible.

The plugin is designed to coexist with render-markdown.nvim by letting
render-markdown.nvim handle non-table Markdown while markdown-table-wrap.nvim
owns pipe table rendering.

Requirements:

- Neovim 0.11+
- No external binary dependencies

==============================================================================
INSTALLATION                                  *markdown-table-wrap-installation*

Example lazy.nvim / LazyVim spec:
>
  return {
    {
      "ice345/markdown-table-wrap.nvim",
      ft = { "markdown", "quarto", "rmd" },
      opts = {},
    },
  }
<

For local development:
>
  return {
    {
      dir = "~/Code/lazyvim-table/markdown-table-wrap.nvim",
      ft = { "markdown", "quarto", "rmd" },
      opts = {},
    },
  }
<

Example LazyVim key bindings:
>
  keys = {
    {
      "<leader>mi",
      "<cmd>MarkdownTableToggleInline<cr>",
      desc = "Toggle Markdown table inline view",
    },
  }
<

ToggleInline selects Inline for the current buffer's editing session without
changing global setup.

COMMANDS                                      *markdown-table-wrap-commands*

                                                        *:MarkdownTablePreview*
:MarkdownTablePreview
    Open the configured preview mode. Defaults to Inline.

                                                  *:MarkdownTableInlinePreview*
:MarkdownTableInlinePreview
    Render the table under the cursor inline.

                                                   *:MarkdownTableFloatPreview*
:MarkdownTableFloatPreview
    Render the table under the cursor in a floating window.

                                             *:MarkdownTableToggleInline*
:MarkdownTableToggleInline
    Switch between Source and Inline. Press again to clear Inline and leave
    Source visible.

                                                  *:MarkdownTableTogglePreview*
:MarkdownTableTogglePreview
    Toggle the active preview.

                                                   *:MarkdownTableClosePreview*
:MarkdownTableClosePreview
    Close the preview and clear inline rendering.

                                                        *:MarkdownTableRefresh*
:MarkdownTableRefresh
    Force refresh Markdown table rendering in the current buffer.

                                             *:MarkdownTableEnableAutoPreview*
:MarkdownTableEnableAutoPreview
    Enable automatic table rendering in the current buffer.

                                            *:MarkdownTableDisableAutoPreview*
:MarkdownTableDisableAutoPreview
    Disable automatic table rendering for the current Source buffer.

                                             *:MarkdownTableToggleAutoPreview*
:MarkdownTableToggleAutoPreview
    Toggle automatic table rendering in the current buffer.

                                                       *:MarkdownTableStatus*
:MarkdownTableStatus
    Show the current rendering state.

                                                       *:MarkdownTableNextCell*
:MarkdownTableNextCell
    Move to the next source table cell.

                                                       *:MarkdownTablePrevCell*
:MarkdownTablePrevCell
    Move to the previous source table cell.

                                                        *:MarkdownTableNextRow*
:MarkdownTableNextRow
    Move to the same source table cell in the next row.

                                                       *:MarkdownTablePrevRow*
:MarkdownTablePrevRow
    Move to the same source table cell in the previous row.

                                                      *:MarkdownTableOpenLink*
:MarkdownTableOpenLink
    Open the first link in the current source table cell.

                                                        *:MarkdownTableExport*
:MarkdownTableExport[!] [tsv|csv]
    Copy the table under the cursor as TSV (the default) or CSV. Add ! to
    export every table in the buffer, separated by blank lines.

    Each cell exports the text it displays: Markdown syntax is removed and
    <br> becomes a line break. The value is written to the unnamed and "0
    registers like a yank, and to "+ / "* when 'clipboard' contains
    unnamedplus / unnamed. TSV escapes tab, carriage return, line break and
    backslash as \t, \r, \n and \\. CSV quotes fields containing commas,
    quotes or line breaks, and prefixes values starting with =, +, -, @, tab
    or carriage return with ' so spreadsheets do not evaluate them as
    formulas; this includes negative numbers. A table whose body rows hold
    more cells than its header is refused, and no register is changed.

CONFIGURATION                              *markdown-table-wrap-configuration*

Default setup:
>
  require("markdown-table-wrap").setup({
    max_width_ratio = 0.9,
    min_col_width = 8,
    max_col_width = 50,
    fit_to_window = true,
    border = "rounded",
    use_unicode_border = true,
    table_border = "rounded",
    row_separator = true,
    preview_mode = "inline",
    inline_mode = "replace",
    inline_position = "above",
    dim_source = true,
    auto_preview = true,
    render_all = true,
    auto_preview_in_insert = false,
    clear_on_cursor_leave = true,
    clear_on_insert = true,
    clear_on_visual = true,
    debounce_ms = 80,
    overlay_priority = 10000,
    quote_icon = "auto",
    highlight_preset = "default",
    theme_dir = nil,
    themes = {},
    extra_filetypes = {},
    highlights = {},
    link = {
      icon = "",
      wiki = {
        icon = " ",
        highlight = "MarkdownTableWrapWikiLink",
        scope_highlight = "MarkdownTableWrapWikiLink",
      },
      image = " ",
      custom = {
        github = { pattern = "github", icon = " " },
        gitlab = { pattern = "gitlab", icon = "󰮠 " },
        youtube = { pattern = "youtube", icon = " " },
        bilibili = { pattern = "bilibili", icon = "󰟴 " },
        cern = { pattern = "cern.ch", icon = " " },
      },
    },
    map_gx = false,
  })
<

Important options:

max_width_ratio~
    Maximum rendered table width as a ratio of the current window's text
    area, clamped to 0.1 through 1.0. The 'number', 'signcolumn', and
    'foldcolumn' widths are subtracted before the ratio applies, so a window
    with a visible gutter renders narrower tables than a bare window of the
    same total width.

min_col_width~
    Minimum display width for a column.

max_col_width~
    Maximum natural display width before wrapping.

fit_to_window~
    Prioritize keeping the complete table inside the current window text area.
    When necessary, columns may become narrower than min_col_width.

preview_mode~
    "inline" (default) or "float". Inline renders in place inside the buffer
    you are editing, which stays modifiable and reveals the raw source row
    under the cursor.

inline_mode~
    "replace" hides the source rows and draws the rendered rows in their
    place.
    "insert" shows rendered rows above or below the source table.

clear_on_visual~
    In inline mode, reveal source Markdown while selecting text and re-render
    after leaving Visual mode.

auto_preview~
    Automatically render supported buffers.

render_all~
    Render all tables in the current Markdown buffer.

quote_icon~                           *markdown-table-wrap-quote-icon*
    Marker drawn in front of every rendered line of a table inside a
    blockquote, once per quote level, using the "quote" highlight. "auto"
    draws render-markdown.nvim's quote bar when that plugin is loaded and the
    raw ">" otherwise. Any string fixes the marker; false draws none. The
    rendered table is narrowed by the marker width so it stays inside the
    quote block. The marker follows the callout kind of the enclosing quote
    ("quote", or "callout_info", "callout_success", "callout_hint",
    "callout_warn", "callout_error"), so "> [!done]" keeps its green bar.

highlight_preset~                  *markdown-table-wrap-highlight-preset*
    "default", "tokyonight", "catppuccin", "render_markdown", "auto", or a
    custom key supplied through |markdown-table-wrap-themes| or
    |markdown-table-wrap-theme-dir|. The default preset links to standard
    Neovim highlight groups so it works naturally with arbitrary colorschemes.

theme_dir~                              *markdown-table-wrap-theme-dir*
    Optional directory containing custom theme files named <preset>.lua.

themes~                                    *markdown-table-wrap-themes*
    Inline custom theme table keyed by |markdown-table-wrap-highlight-preset|.
    For example, set highlight_preset = "my_theme" and provide
    themes.my_theme.

link~
    Icon configuration for links, wiki links, images, and URL pattern matches.
    Standard Markdown links use [text](url). The plugin also accepts
    (text)[url] as a convenience form inside table cells.

map_gx~                                    *markdown-table-wrap-map-gx*
    Opt into a buffer-local gx mapping for table links in Source buffers.
    Defaults to false, leaving the user's existing mapping untouched.
    |:MarkdownTableOpenLink| can also be mapped manually.

extra_filetypes~
    List of additional filetypes to enable table rendering for. The default
    is {}, meaning the built-in markdown, md, quarto, rmd, and rmarkdown
    filetypes render tables. Example:
>
      require("markdown-table-wrap").setup({
        extra_filetypes = { "text" },
      })
<
    NOTE for LazyVim users: If you add extra filetypes, you must also
    include them in the plugin's ft list to load the plugin for those
    filetypes:
>
      return {
        {
          "ice345/markdown-table-wrap.nvim",
          ft = { "markdown", "quarto", "rmd", "text" },
          opts = {
            extra_filetypes = { "text" },
          },
        },
      }
<

==============================================================================
LUA API                                      *markdown-table-wrap-api*

The inspection helpers return effective per-buffer state without changing it.

get_buffer_config({bufnr})~      *markdown-table-wrap.get_buffer_config()*
    Return a deep-copied effective configuration for {bufnr}, including
    runtime view and auto-preview overrides. Omit {bufnr} or pass 0 for the
    current buffer.

get_preview_mode({bufnr})~          *markdown-table-wrap.get_preview_mode()*
    Return the effective "inline" or "float" mode for {bufnr} without
    mutating global setup. Omit {bufnr} or pass 0 for the current buffer.

Example:
>
  local table_wrap = require("markdown-table-wrap")
  local config = table_wrap.get_buffer_config(0)
  local mode = table_wrap.get_preview_mode(0)
<

export_table({opts})~                   *markdown-table-wrap.export_table()*
    The Lua entry point behind |:MarkdownTableExport|. Return true and the
    exported text, or false without changing any register. {opts} accepts:
      format              "tsv" (default) or "csv".
      all                 Export every table in the buffer.
      csv_formula_policy  "raw" keeps formula-leading CSV values unprefixed.
      silent              Suppress the notification.

HIGHLIGHTS                                  *markdown-table-wrap-highlights*

Highlight groups:

- MarkdownTableWrapBorder
- MarkdownTableWrapHeader
- MarkdownTableWrapInline
- MarkdownTableWrapSource
- MarkdownTableWrapCode
- MarkdownTableWrapBold
- MarkdownTableWrapItalic
- MarkdownTableWrapStrike
- MarkdownTableWrapLink
- MarkdownTableWrapWikiLink
- MarkdownTableWrapImage
- MarkdownTableWrapMark
- MarkdownTableWrapQuote
- MarkdownTableWrapCalloutInfo
- MarkdownTableWrapCalloutSuccess
- MarkdownTableWrapCalloutHint
- MarkdownTableWrapCalloutWarn
- MarkdownTableWrapCalloutError

Semantic highlight groups are reapplied after ColorScheme. A direct custom
spec replaces the preset's linked base for that semantic key.

Content highlight keys are background-transparent when they only link to an
existing highlight group. This prevents Inline replace mode from drawing a
filled rectangle for every cell when a colorscheme gives Normal, Title, or
another linked group a background. Add an explicit `bg` to opt into a filled
background.

Inline-code delimiters inside link or image labels are removed from the
display text before width calculation. This keeps concealed backticks from
shifting the rendered table separators in Inline mode.

Override by semantic key:
>
  require("markdown-table-wrap").setup({
    highlights = {
      code = { fg = "#9ece6a" },
      bold = { fg = "#e0af68", bold = true },
      link = { fg = "#7dcfff", underline = true },
      mark = { fg = "#1a1b26", bg = "#e0af68" },
    },
  })
<

==============================================================================
RENDER-MARKDOWN.NVIM                    *markdown-table-wrap-render-markdown*

To avoid double table rendering, disable render-markdown.nvim pipe tables:
>
  return {
    "MeanderingProgrammer/render-markdown.nvim",
    opts = {
      pipe_table = {
        enabled = false,
      },
    },
  }
<

Blockquoted tables work with this setup too. Their source lines are hidden
entirely, so render-markdown.nvim never draws its quote bar on them; the
rendered rows carry the marker themselves and the "auto" setting of
|markdown-table-wrap-quote-icon| picks the same bar. Callout bars keep their
severity color; the default preset links to the Diagnostic* groups, which is
what render-markdown.nvim colors callouts with, and the render_markdown preset
links to its RenderMarkdown* groups.

==============================================================================
LIMITATIONS                                *markdown-table-wrap-limitations*

- Inline replacement draws the rendered rows as virtual lines. These are
  visual rows, not real buffer rows; use |:MarkdownTableFloatPreview| for a
  normal scrollable preview buffer.
- Treesitter-aware table discovery is not implemented yet.
- Container-prefixed tables nested inside lists are not implemented yet. Such
  container starts safely terminate a top-level table. Blockquoted tables are
  supported; see |markdown-table-wrap-quote-icon|.
- The plugin focuses on Markdown pipe tables and does not replace general
  Markdown rendering.
